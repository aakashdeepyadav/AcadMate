Security Protocol

5-Layer Anti-Proxy Protocol

Making attendance fraud statistically and practically impossible.

01 🔐

Hardware Binding

Account locked to a single ANDROID_ID — no phone passing

02 🔊

Acouximity™

18.5kHz near-ultrasonic handshakes prove physical classroom presence

03 👁️

ML Face Liveness

Google ML Kit detects blinks & micro-movements — blocks photo/video spoofing

Architecture

9-Module Scalable Architecture

Clean Architecture with MVVM, Kotlin Flow, and strict module boundaries.

:app

Entry point, role-aware navigation

:auth

OTP verification, smart-lookup

:attendance

5-layer engine, acoustic processing

:ai

Gemini suite, audio summarization

:dashboard

Home, Profile, Timetable screens

:admin

Institutional tools, master syllabus

:assignments

Grading, Gradebook, submissions

:designsystem

Unified UI library, themes

:core

Shared entities, alarm schedulers
